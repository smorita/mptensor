# Signed Index/Axes/Shape and Negative Indexing: Design

- Date: 2026-10-02
- Target branch: `develop`

## 1. Goals

Accept negative values (counting from the end) for axis specifications and element indices, as numpy does.

- The public `Index` / `Axes` / `Shape` types hold signed integers (`std::ptrdiff_t`).
- Internal computation keeps using `size_t`. Public API entry points normalize their arguments with context-specific conversion functions.
- Replace the fixed-arity constructors generated by `index_constructor.py` with a C++17 variadic template and a `std::initializer_list` constructor.
- Introduce GoogleTest for the new tests.

## 2. Scope

### In scope

| Item | Description |
|---|---|
| Axis specification | Negative values in `Axes` arguments and scalar axis arguments (`n_axes`) are interpreted relative to `rank` |
| Element indices | Negative begin/end values in `get_value` / `set_value` / `slice` / `set_slice` are interpreted relative to the size of each dimension |
| Scalar arguments | `n_axes`, `i_begin`, `i_end` of `slice` / `set_slice` and `n_axes` of `multiply_vector` become `std::ptrdiff_t` |
| Return values | `shape()`, `global_index()`, `range()`, etc. return the public (signed) type |
| Constructors | Variadic template + `initializer_list`. The generator script and the generated header are removed |
| Tests | Introduce GoogleTest and add `tests/index` and `tests/tensor` |

### Out of scope

- Inferring a dimension from `-1` in `reshape` (negative values in a `Shape` are an error).
- Detecting duplicate axes after normalization (left to the existing `debug::check_*` assertions).
- Converting the existing `debug::check_*` assertions into exceptions.
- Arguments that represent counts (`upper_rank`, `urank`, `target_rank`, etc.) stay `size_t`.
- Any change to `tests/legacy`.

## 3. Types

Define the following in `include/mptensor/index.hpp`.

```cpp
namespace mptensor {

template <typename T>
class BasicIndex {
 public:
  using value_type = T;
  using index_t = std::vector<T>;

  BasicIndex();
  BasicIndex(const index_t& index);
  BasicIndex(std::initializer_list<T> list);
  template <typename... Ints,
            typename = std::enable_if_t<(sizeof...(Ints) > 0) &&
                                        (std::is_integral_v<Ints> && ...)>>
  BasicIndex(Ints... js);  // not explicit: keeps implicit conversion from integers

  const T& operator[](size_t i) const;
  T& operator[](size_t i);
  size_t size() const;
  void push(T i);
  void resize(size_t n);
  void assign(size_t n, const T j[]);
  void sort();
  BasicIndex inverse() const;
  bool operator==(const BasicIndex&) const;
  BasicIndex& operator+=(const BasicIndex&);

 private:
  index_t idx;
};

template <typename T>
std::ostream& operator<<(std::ostream&, const BasicIndex<T>&);
template <typename T>
BasicIndex<T> operator+(const BasicIndex<T>&, const BasicIndex<T>&);

using Index = BasicIndex<std::ptrdiff_t>;  // public type

namespace detail {
using UIndex = BasicIndex<size_t>;  // internal use only
}

Index range(std::ptrdiff_t start, std::ptrdiff_t stop);
Index range(std::ptrdiff_t stop);  // range(0, stop)

}  // namespace mptensor
```

- `Axes` and `Shape` remain aliases of `Index` (in `tensor.hpp`).
- The variadic constructor accepts any integer type and throws when a value is not representable in `T`.
  - An unsigned value greater than `PTRDIFF_MAX` passed to `Index` → `std::out_of_range`
  - A negative value passed to `UIndex` → `std::out_of_range`
- A single-argument constructor creates an `Index` of length 1 (both `Index(3)` and `Index{3}` are `[3]`).
- The whole implementation lives in header templates. The following files are removed:
  - `include/mptensor/index_constructor.py`
  - `include/mptensor/index_constructor.hpp`
  - `src/index.cc` (sources are collected with glob / `find`, so no build configuration change is needed)
- Related updates:
  - Remove `PATTERN "index_constructor.py" EXCLUDE` from the install rule in `src/CMakeLists.txt`.
  - Regenerate `src/Makefile.depend` so that it no longer refers to `index_constructor.hpp` or `index.o`.

## 4. Conversion functions

These are public functions placed in `index.hpp`. Exception messages include the offending value, its position (element number), and the `rank` or size.

| Function | Accepted range | Conversion | Error |
|---|---|---|---|
| `size_t normalize_axis(std::ptrdiff_t a, size_t rank)` | `[-rank, rank)` | add `rank` if negative | `std::out_of_range` |
| `detail::UIndex normalize_axes(const Axes& axes, size_t rank)` | each element as above | same | `std::out_of_range` |
| `size_t normalize_index(std::ptrdiff_t i, size_t n)` | `[-n, n)` | add `n` if negative | `std::out_of_range` |
| `detail::UIndex normalize_index(const Index& idx, const detail::UIndex& shape)` | each element as above | same | `std::invalid_argument` on length mismatch, `std::out_of_range` when out of range |
| `size_t normalize_slice_end(std::ptrdiff_t e, size_t n)` | `[-n, n]` | add `n` if negative | `std::out_of_range` |
| `detail::UIndex to_internal_shape(const Shape& s)` | each element `>= 0` | unchanged | `std::invalid_argument` |
| `Index to_public(const detail::UIndex& u)` | each element `<= PTRDIFF_MAX` | unchanged | `std::out_of_range` |

`range(start, stop)` lists the values as they are (`range(-2, 0)` is `[-2, -1]`). `start > stop` throws `std::invalid_argument`.

## 5. Public API changes

### 5.1 Basic pattern

Public functions take public types, normalize them exactly once at the entry point, and call a `detail::*_impl` function. Internal calls pass `detail::UIndex` directly, so there is no double normalization and no round trip through the public type.

```cpp
template <typename M>
Tensor<M> transpose(const Tensor<M>& a, const Axes& axes, size_t urank) {
  return detail::transpose_impl(a, normalize_axes(axes, a.rank()), urank);
}
```

Normalization (and any exception it throws) happens before any MPI communication or modification of a tensor. Consequently, when an exception is thrown, no rank leaves in the middle of a communication, and the tensors are left unchanged.

### 5.2 `Tensor` members

| Item | Change |
|---|---|
| `Dim`, `axes_map` (private) | `detail::UIndex` |
| `shape()` | returns `Shape` by value (`to_public(Dim)`) |
| `internal_shape()` (new) | returns `const detail::UIndex&`; documented as internal |
| `global_index(size_t i)` | returns `Index` |
| `global_index_fast`, `local_position`, `get_axes_map` | use `detail::UIndex`; documented as internal |
| `get_value`, `set_value` | `normalize_index(idx, Dim)` |
| `transpose(const Axes&)` (member) | `normalize_axes` |
| `multiply_vector(..., n_axes, ...)` (each of the 1–4 pair overloads) | `n_axes` becomes `std::ptrdiff_t`; `normalize_axis` |
| `set_slice(a, n_axes, i_begin, i_end)` | arguments become `std::ptrdiff_t`; the axis uses `normalize_axis`, begin uses `normalize_index`, end uses `normalize_slice_end` |
| `set_slice(a, index_begin, index_end)` | rules in Section 5.4 |
| Constructors such as `Tensor(const Shape&)` | `to_internal_shape` |

### 5.3 Free functions

| Function | Change |
|---|---|
| `Axes` arguments of `transpose`, `trace`, `contract`, `tensordot`, `svd`, `psvd`, `qr`, `eigh` (including the generalized version), `eig`, `solve`, `rsvd` | `normalize_axes` |
| `slice(a, n_axes, i_begin, i_end)` | same as the scalar version of `set_slice` |
| `slice(a, index_begin, index_end)` | rules in Section 5.4 |
| `Shape` arguments of `reshape`, `extend` | `to_internal_shape` |

### 5.4 Slice rules

Each axis is processed as follows, where `n` is the size of that axis.

1. If the raw values before normalization satisfy `begin == end`, the axis is not sliced and the full range is taken (`Index` version only; keeps the existing behavior).
2. Otherwise, normalize `begin` with `normalize_index(begin, n)` and `end` with `normalize_slice_end(end, n)`.
3. If `begin >= end` after normalization, the slice is empty and `std::out_of_range` is thrown.

Examples (`n = 5`):

| begin | end | Result |
|---|---|---|
| 0 | 0 | full range `[0, 5)` |
| 1 | -1 | `[1, 4)` |
| -2 | 5 | `[3, 5)` |
| 2 | -3 | `[2, 2)` after normalization → exception |

The scalar versions (`slice(a, n_axes, i_begin, i_end)` and the scalar `set_slice`) do not apply rule 1, as before; only rules 2 and 3 apply.

### 5.5 Compatibility impact (breaking changes)

- `shape()` returns a value instead of a reference. `const Shape& s = a.shape();` binds to a temporary (it still works thanks to lifetime extension).
- `Index::operator[]` returns `std::ptrdiff_t&`. Code that binds the result to `size_t&` breaks.
- The signatures of `global_index_fast`, `local_position`, and `get_axes_map` change.
- The file format of saved tensors does not change (the internal `size_t` values are written as text).

## 6. Error handling

- Only the new conversion functions and the variadic constructor throw exceptions.
  - Out-of-range axis or element index → `std::out_of_range`
  - Invalid shape or length mismatch → `std::invalid_argument`
- Behavior under MPI (to be documented in Doxygen):
  - If the exception is not caught, `std::terminate` → `abort` ends the whole job, just like a failed `assert`.
  - If every rank passes the same arguments to a collective operation, all ranks throw at the same time, so the exception can be caught and execution can continue.
  - If only some ranks throw, catch, and continue, the program may deadlock (passing the same arguments on all ranks is a precondition).
  - `get_value` / `set_value` involve no communication, so different arguments on different ranks are fine.

## 7. Tests

### 7.1 CMake

- Change `cmake_minimum_required` to `VERSION 3.16...3.31`.
- When `BUILD_TESTS=ON`:
  1. Try `find_package(GTest CONFIG)`.
  2. If not found, fetch GoogleTest `v1.17.0` with `FetchContent` (`INSTALL_GTEST=OFF`). In offline environments, a local source tree can be given with `FETCHCONTENT_SOURCE_DIR_GOOGLETEST`.

### 7.2 Layout

```
tests/
├── CMakeLists.txt          # obtain GoogleTest; add_subdirectory(index / tensor)
├── legacy/                 # unchanged
├── gtest_mpi_main.cc       # shared MPI-aware main
├── index/
│   ├── CMakeLists.txt      # registered per test case with gtest_discover_tests
│   └── *.cc
└── tensor/
    ├── CMakeLists.txt      # MPI enabled: mpiexec -n 1 / -n 4; disabled: serial
    └── *.cc
```

### 7.3 `gtest_mpi_main.cc`

- With MPI: `MPI_Init` → `testing::InitGoogleTest` → `RUN_ALL_TESTS` → `MPI_Allreduce` (logical OR of failures) → `MPI_Finalize`. If any rank fails, every rank returns a non-zero exit code.
- On ranks other than 0, remove the default result printer and register a listener that prints only failed assertions, prefixed with `[rank N]`.
- When `_NO_MPI` is defined, it behaves as a normal gtest main.

### 7.4 `tests/index`

- Constructors: mixed integer types (`int`, `long`, `size_t`, `std::ptrdiff_t`); `Index(0, 1, -1)` and `Index{0, 1, -1}` give the same result; implicit conversion `Axes a = 2;`; 17 or more arguments; exceptions for out-of-range values.
- `normalize_axis` / `normalize_axes`: conversion of `-rank`, `-1`, `0`, `rank-1`, and exceptions for `-rank-1` and `rank`.
- `normalize_index` (scalar and `Index` versions): the same boundary values, and `std::invalid_argument` on length mismatch.
- `normalize_slice_end`: accepts `n`; throws for `n+1` and `-n-1`.
- `to_internal_shape`: `std::invalid_argument` for negative values.
- `to_public`: values are preserved through a round trip.
- `range`: negative ranges, empty when `start == stop`, exception when `start > stop`.
- `sort`, `inverse`, `operator==`, `operator+`, `operator<<` work for both `Index` and `UIndex`.

### 7.5 `tests/tensor`

Use `TYPED_TEST` to cover both `double` and `complex` value types. The matrix type is `scalapack::Matrix` with MPI and `lapack::Matrix` without.

- A call with negative values gives the same result as the equivalent call with non-negative values:
  `transpose` (member and free function), `tensordot`, `contract`, `trace`, `svd`, `qr`, `eigh`, `multiply_vector`, `slice` / `set_slice` (scalar and `Index` versions, negative end, full range when the raw begin == end), `get_value` / `set_value`.
- Exceptions:
  - Out-of-range axes or element indices make every rank throw `std::out_of_range`.
  - After catching the exception, collective operations (e.g. `tensordot`) can continue without deadlock (run with 4 processes).
  - The target tensor is unchanged after the exception.
  - A `Shape` containing a negative value throws `std::invalid_argument`.

### 7.6 Regression checks

- `tests/legacy` (including `file_io`) passes without modification.
- Everything under `examples/` builds.
- New and modified code produces no warnings with `-Wall -Wextra -Wsign-compare`.
